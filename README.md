# Working notes on OpenAI's quasi-Riemann hypothesis papers

> These are working notes, generated by Claude and Codex to help me read the papers on the
> quasi-Riemann hypothesis that OpenAI released
> ([github.com/openai/math](https://github.com/openai/math/tree/main/preprints)).
> — Michael Rubinstein

- [Sixth powers in a mean square: an accessible guide to the 11/12 argument for ζ(s)](zeta_11_12_guide.pdf) (PDF, 11 pages)
- [Zeros of a whole family: an accessible guide to the 7/8 argument for ζ(s)](zeta_7_8_guide.pdf) (PDF, 12 pages)
- [A zero-free strip for the L-functions of the elliptic curves y² = x³ + d: the 11/12 method and its extension to 7/8](cm_zero_free_strip.pdf) (PDF, 29 pages; [TeX source](cm_zero_free_strip.tex)).
  This note adapts the two methods to the CM curves y² = x³ + d rather than explaining OpenAI's papers.
  As it states, these are working notes whose details have yet to be checked carefully; the 7/8 part
  is an outline of a proof that is conditional on statements listed in its Section 16.

All three notes are also posted at <https://www.math.uwaterloo.ca/~mrubinst/quasi_rh_notes/>.
