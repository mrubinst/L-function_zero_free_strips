# Tests for the s3 insert (Appendix B: the zero detector for a CM target)

Run everything with `./run_all.sh` (about 70 s). You need python3 with sympy, mpmath and numpy, and PARI/GP
(`gp`) for t3. Each claim prints one line, `[STATUS] <id> <where> <claim> :: <details>`. A tested claim passes
only if it holds and its falsifier (a deliberately wrong variant) fails. Outputs of the last run are in
`outputs/`. `lib/` holds unchanged copies of `zw.py`, `common.py`, `fastgauss.py`, `cmcommon.py` and
`cmreport.py` from `tests_cm/part_C_lines_0998_1509/lib`. `s3lib.py` adds factorization of elements of large
norm, the members `phi_{u,nu,sigma}` of X_u, and a randomized conductor search. The search assumes a generous
candidate modulus and tests 50 random congruence representatives at each candidate exponent; its results are
finite sanity checks, not exact or exhaustive conductor proofs. `apply_edits.py` applies
`../edits.md` and `../inserts.tex` to a copy of the guide in `../build/`. The patched guide compiles with no
undefined references and no overfull boxes.

Conventions: those of OAI78 and the guide. omega = e^{2 pi i/3}, primary = 1 mod 3, lambda = 1 + 2 omega,
chi_n(u) = (u/n)_6 with zero values kept, alpha(n) = n/|n|. The model group Theta_0 is generated by the Kummer
characters chi_.(lambda), chi_.(2), chi_.(omega) and chi_.(-1), whose conductors lie over 2 and 3; it has order
216. The model target is psi = abar * chi_.(lambda).

Caveats (reviewer, 2026-10-12):
- The 180 conductor cases of S3-T2 (`t2_conductors.py`) use randomized congruence sampling: a candidate modulus g is
  accepted if the member agrees with its infinity type at 50 random x = 1 mod g, and the search starts from an
  assumed bound 2^4 lambda^6 prod pi^2. They are checks, not exhaustive exact conductor computations.
- The functional-equation checks S3-T3a and S3-T3b start from the Euler coefficients of the member (PARI
  `lfuncheckfeq`), not from the functional equation. They are stronger, independent evidence than the s2 checks,
  which construct the tested function from the functional equation itself and so establish consistency.

Exit status (2026-10-12): each script exits 1 if a claim line is FAIL (including a falsifier that did not fail),
through the atexit hook of `s3lib.report`; `CM_TESTS_FORCE_FAIL=1` makes the first claim fail, as a self-test.
`./run_all.sh` exits 1 if any script exits nonzero or prints a failure line.
